# BlogCTL v0.1.193

发行包整理：Windows、Linux、macOS 的 6 个 CPU/OS 目标现在同时提供含原项目 MIT 许可证的 ZIP 安装包，继续保留原始可执行文件供现有用户直接升级；浏览器扩展 ZIP 同时包含项目 LICENSE 和已有的 i18next 许可证。Release 根目录单独附带 LICENSE，全部产物计入 SHA256SUMS。

没有改变本地 Native Messaging、MCP、第三方发布逻辑或个人配置目录。下载对应架构 ZIP、核对 SHA-256 后，解压并沿用原有 `blogctl install` 和浏览器扩展安装流程即可。

Version: `0.1.193`

# BlogCTL v0.1.192

与新版 Inkerio 内容配置一致：分发编译时从配置的内容根目录读取 `src/content/site/copyright.json`，与站点文章、笔记和摄影页面共用双语版权声明。调整版权文案后，新编译的分发文章即可生效，无需重新构建 BlogCTL；兼容没有该文件的旧内容库，已存在但无效的策略文件会阻止编译，避免错误授权声明发布。

此次仅更新本地编译逻辑与版本号，不自动覆盖已分发的历史文章；现有 `blogctl.toml`、Native Messaging 和 Canonical 设置保持不变。

版本：`0.1.192`

# BlogCTL v0.1.191

统一博客内容与分发平台的版权说明。BlogCTL 在原有的首发链接和 UTM 页脚后增加中英文版权声明与不带跟踪参数的原文链接，保留用户已有的 `blogctl.toml` 页脚模板、Canonical 设置和远端更新语义。同步 Inkerio 页面中的文章、笔记和生活记录版权规则，规范原创文字、摄影及第三方素材的版权边界。

本次发布不会自动更新既有第三方平台文章；创建或明确更新文章时才会写入新版声明。

版本：`0.1.191`

# BlogCTL v0.1.190

MCP 新增本地图片隐私清理和 R2 上传：支持 JPEG/PNG/WebP、EXIF 自动旋转与去除元数据、实际输出校验、SHA-256 版本化地址、仅本地 Dry Run。允许读取路径限定为 content_root 或配置的 image_upload_roots，沿用 R2 配置，不修改原图、不传输原始图片到 MCP。已新增单元与 Sharp 真实元数据测试。

版本：`0.1.190`

# BlogCTL v0.1.189

新增原生 MCP STDIO 接口，复用原有 Bridge、发布编译器、浏览器扩展和任务状态，支持文章查询、发布预检、创建/更新草稿、发布及任务查询。MCP 通过本地 Bridge 发起浏览器登录态刷新，后台扩展自动同步已有会话，无需手动打开控制台；Cookie 和密钥不返回 MCP。新增 request_id 同任务去重及配套测试和文档。

保留原有的发布/重试语义，不新增 Skill、SQLite、公开 HTTP MCP 监听或 TOML 权限配置。仍需安装本机浏览器扩展并保持登录。完整说明见 `docs/MCP.md`。

版本：`0.1.189`

# BlogCTL v0.1.188

修复头条正式文章目录无法跳转：compiler 根据原文目录链接，为对应标题生成匹配的 id；目录层级压平时保留有效链接，正文章节引用同样保留，仅无目标的引用转为文字。

版本：`0.1.188`

# BlogCTL v0.1.180

创建页改为手动检测文章关联，检测不再作为创建草稿的前置条件。

## 创建页

- 打开创建页、切换本地文章、刷新页面和创建任务完成后，不再自动检测远端文章关联。
- 顶部「重新检测」改为「检测」，点击后检测勾选的平台；平台卡片保留「检测关联」。
- 未检测、检测中或检测失败时，均可直接创建草稿或创建并发布。
- 仅在实际检测时展示检查中的提示，未检测不再显示为正在检查。
- 已检测到对应文章的平台仍从批量新建中排除，保留 Hashnode 已关联草稿的继续同步入口。
- 保留运行中任务的重复提交保护。更新页仍按原流程检测并选择远端目标。

## 验证

- 扩展回归测试 77 项通过，覆盖无自动检测、检测中创建、检测失败后创建，以及切换文章后丢弃过期结果。
- BlogCTL 完整验证通过。

## 升级

CLI、Bridge、Native Host 与 Extension 版本统一为 `0.1.180`。更新后重新加载浏览器扩展，使创建页行为生效。

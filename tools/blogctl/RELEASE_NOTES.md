# BlogCTL v0.1.182

修复 Medium 已发布文章在「更新所选」提交时仍被旧平台白名单拦截的问题。支持保存待发布编辑版本，继续禁止自动发布。

Medium 正文的章节引用指向博客原文对应章节，避免把博客锚点错误地用于 Medium 自动生成的段落 ID。创建、更新和复制 HTML 使用相同规则。

原生 Story settings 自动保存并重新打开回读 Canonical，不触发 Save and publish；失败时任务明确报告正文已保存但设置未完成。

验证覆盖真实前端提交路径、发布拦截及章节引用编译；保留 Windows Data、配置和文章关联。

版本：`0.1.182`

# 发布操作的安全边界

检测远端内容是只读操作，创建、更新和发布是可能产生副作用的操作，必须单独确认。

| 操作 | 对远端的影响 | 必要条件 |
| --- | --- | --- |
| 检测、查询 | 只读 | 选择平台和已登录会话 |
| 创建草稿 | 新增文章 | 用户确认，且关联检测未发现已有目标 |
| 更新文章 | 修改指定文章 | 明确远端 ID，平台支持此能力 |
| 发布草稿 | 可能公开文章 | 明确草稿 ID，平台提供已验证的发布能力 |
| 提交索引 | 通知搜索引擎 | 明确索引任务和 Provider |

例如，创建草稿时网络超时，平台可能已写入成功。此时应先查询任务和远端文章，再决定是否重试，以免产生重复草稿。

更新必须保留用户选择的远端目标，不能在更新失败后自动改为创建。相关细节见[工作流](../guide/workflows.md)和[运行时 Contracts](../reference/contracts.md)。

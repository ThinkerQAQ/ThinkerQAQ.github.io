# 每个操作会改变什么

| 操作 | 对远端的影响 | 如何选择目标 |
| --- | --- | --- |
| 检测账号内容 | 读取 | 平台与登录会话 |
| 检测关联 | 查询本地文章对应的候选 | 本地文章与平台 |
| 创建草稿 | 新增文章 | 本地文章；检测可选 |
| 更新 | 替换指定内容 | 明确远端 ID |
| 发布草稿 | 平台支持时公开所选草稿 | 已知草稿 ID |
| 提交索引 | 通知搜索服务 | 配置的站点与 Provider |

检测不会授权发布，也不建立持久文章绑定。点击创建是独立决定：即使旧任务曾写过这篇文章，创建仍会新增草稿。

写入超时可能发生在平台已经保存之后。任务保留远端 ID 和事件，便于检查结果。创建/发布没有通用盲目重试；符合条件的 Medium 恢复会继续任务记录中的草稿或已保存编辑版本。单目标且不带发布的更新可提供原目标重试。

Medium 的待发布编辑版本还不是新的公开正文，需用户在 Medium 点击 **Save and publish**。不支持的更新会报错，不会静默另建文章。平台操作和恢复方式见[工作流](../guide/workflows.md)。

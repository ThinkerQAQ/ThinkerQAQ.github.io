# 工作台操作

## 检测

选择平台与状态，读取远端文章、草稿、ID 和编辑链接，不产生远端写入。

## 创建

选择本地文章，完成远端关联检测。检测成功且不存在匹配内容时可创建草稿；超时后应先重新查询，避免重复创建。

## 更新

必须选中明确的远端 ID，不允许自动转成创建。已发布正文更新目前仅支持博客园与 DEV.to。

## 发布

仅对支持 `PublishDraft` 的平台执行明确的草稿发布任务。开源中国的直接发布能力目前关闭。

## 任务与索引

任务页展示状态、远端 ID 和事件。索引通过 IndexNow、百度或 Google Search Console 独立执行。

## Web Console

扩展中的「打开工作台」进入 `http://127.0.0.1:32145/console/`。涉及浏览器身份的操作由扩展转发，网页本身不持有 Cookie 或 Bridge Token。

# 创建、更新与发布文章

扩展侧边栏和 Web Console 使用同一套操作。发布前，在「设置」填写引擎和内容路径，确认目标平台的文章语言，并在同一浏览器配置中登录该平台。DEV.to 也支持 API Key。

## 检测：查看账号内容

打开「检测」，选择平台，用「草稿 / 已发布 / 全部」筛选。结果显示远端标题、ID 和编辑/查看链接。这一步读取账号内容，不要求选择本地文章，也不建立文章绑定。

账号列表和文章关联是两种查询：「检测」页列出账号内容；创建/更新页的「检测关联」将选定本地文章与远端候选比较。标题匹配只是候选，更新前应打开远端链接确认。

掘金最多列出最近 500 篇草稿，达到上限会提示截断。列表失败或截断时，不能据此判断文章不存在。DEV.to 编辑链接需要平台返回的完整 URL，其中的 `temp-slug` 后缀必须保留；只有数字 ID 时无法可靠生成编辑链接。

## 创建：新增文章

1. 打开「创建」，选择本地文章并勾选平台。
2. 按需点击顶部「检测」或平台卡片的「检测关联」。
3. 检查匹配结果；已有文章应转到「更新」。
4. 点击「创建草稿」，或在平台支持时选择「创建并发布」。
5. 在「任务」中逐个平台检查结果和远端链接。

**检测为手动、可选操作。** 切换文章、刷新页面和任务完成不会自动发起检测。未检测、检测中或检测失败均不阻止创建；但已检测出对应文章的平台会从批量新建中排除。写入任务执行期间会禁用创建，防止重复提交。

创建始终新增草稿，不复用旧发布绑定。「创建并发布」先创建，再调用平台发布操作。若第二步失败，先检查已保存的草稿 ID，不要再创建一篇。

## 更新：选择准确目标

1. 打开「更新」，选择本地文章和平台。
2. 点击「检测关联」。
3. 打开候选链接，勾选要覆盖的远端文章；可多选。平台支持时，也可输入已知草稿 ID。
4. 点击「更新所选」，或在可用时选择「更新并发布」。
5. 检查任务结果和远端编辑器。

更新必须有远端 ID，失败后不会自动变为创建。任务保存选定目标、远端状态及可取得的版本信息。某个平台失败不会撤销其他平台已经完成的写入。

| 目标 | 当前界面行为 |
| --- | --- |
| 支持平台的草稿 | 替换选中的草稿 |
| 博客园或 DEV.to 已发布文章 | 更新现有公开正文；博客园还会检查检测到的远端版本 |
| 今日头条已发布文章 | 检查检测时的远端版本后，向同一文章提交更新 |
| Medium 已发布文章 | 保存编辑器中的待发布版本，由用户在 Medium 点击 **Save and publish** 后公开 |
| 其他平台已发布文章 | 当前普通界面不提供已发布正文更新 |

Medium 保存编辑版本后，公开页面仍可能是旧正文。应检查编辑器中的版本，不能只看公开 URL。详见 [Medium 编辑器说明](../medium-har-contract.md)。

## 发布已有草稿

任务保存草稿 ID 且平台支持时，可以执行「发布草稿」。它针对该 ID 调用发布操作，不会另建草稿；部分平台会要求同时传入当前本地文章内容。

平台目录目前向博客园、掘金、CSDN、思否、知乎、51CTO、今日头条、DEV.to 和 Medium 开放显式发布。开源中国和 Hashnode 不提供这个动作；Hashnode 仍可检测账号内容、创建和更新草稿。今日头条已恢复账号检测、创建/更新草稿和显式发布。写入依赖已安装的扩展和已登录的头条创作账号，BlogCTL 在后台编辑器中发送浏览器原生签名请求。请求被领取后不会因断连自动重发。发布成功表示已提交平台审核；重试前应检查远端状态，避免重复提交。实际操作以当前安装版本中启用的按钮为准，平台和账号条件仍可能使请求失败。

## 处理部分失败

| 结果 | 下一步 |
| --- | --- |
| 已返回草稿 ID，后续图片或保存失败 | 打开对应草稿，不要认为完全没有创建 |
| 部分平台成功 | 保留成功结果，只排查失败平台 |
| 写入请求超时 | 先查看「任务」和远端状态，再决定是否提交 |
| 界面提供重试 | 确认保留的目标；单目标更新或符合条件的 Medium 恢复可复用原目标 |
| 无重试入口 | 先判断远端结果，再明确发起需要的新操作 |

创建和发布没有通用的盲目重试。Medium 针对已分配草稿或符合条件的已保存编辑版本有专门恢复流程，使用任务记录中的 ID，并先验证内容。不要向内部恢复请求填入另一篇文章 ID。旧 `publications.json` 用于历史记录，当前显式创建/更新不靠它选择目标。

## 索引与社交短文

索引独立于文章发布。IndexNow、百度和 Google Search Console 使用已保存的搜索站点配置，提交被接收不代表已经收录。360/搜狗当前返回 `submission_not_implemented`，不会执行远端提交，详见[索引排查](../how-to/diagnose-index-submission.md)。

社交短文使用独立的 [Buffer 流程](social-publishing.md)：本地草稿、检查、暂存为 Buffer 私有草稿，再明确公开发布。

## 工作台连接

通过扩展打开 `http://127.0.0.1:32145/console/`。保持扩展启用，网页需要它转发受限请求。页面能打开不代表浏览器会话和 Bridge 已连通，失败时按 [Bridge 排查指南](../how-to/debug-bridge.md)检查。

### 今日头条的章节引用

头条预览不保留网页标题锚点。BlogCTL 将目录与正文中的 `#章节` 链接转为原有文字，保留强调和行内代码；GitHub、官方文档和博客原文等外部链接保持不变。头条预览页可能禁用整个正文的鼠标交互，不能据此判定正式文章外链已失效。

更新已发布头条文章时，应先检测并选择带远端版本的目标；版本变化或目标仍在审核时拒绝覆盖。更新成功表示已重新提交平台处理，不保证立即公开生效。

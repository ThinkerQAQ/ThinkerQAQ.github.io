# 创建前检查已有文章

文章可能已经分发到目标账号时，建议先检查。未检测并不妨碍创建。

1. 确认扩展与 Bridge 已连接，并登录正确的平台账号。
2. 在「检测」查看账号的草稿和已发布文章。
3. 到「创建」选择本地文章与平台，点击顶部「检测」或卡片上的「检测关联」。
4. 打开候选链接，与本地原文比较。已有文章到「更新」选择对应远端 ID。
5. 新文章选择「创建草稿」，再到「任务」检查返回的草稿 ID。

创建页不会自动检测。检测失败不会禁用创建按钮，但也不能证明远端没有文章。已检测出对应文章的平台会从批量新建中排除；写入任务运行时不能重复提交创建。

发生超时后，先检查任务保存的 ID 与远端列表。失败或截断的列表不等于完整账号清单。更多说明见[完整工作流](../guide/workflows.md)。

# 创建草稿前检查远端文章

对于已经跨平台同步过的文章，先检测关联能避免重复创建。

## 操作

1. 确保扩展和 Bridge 已连接，账号处于登录状态。
2. 在「检测」页查看目标平台的文章与草稿。
3. 进入「创建」，选择本地文章，等待关联检测结束。
4. 若发现匹配文章，打开编辑或查看链接，或者进入「更新」明确选择已有远端目标。
5. 只有检测成功且未发现匹配时，才点击「创建草稿」。
6. 完成后到「任务」查看远端 ID。

## 异常处理

远端查询失败、列表截断或者创建请求超时，都不能当作“远端不存在”的证据。先重新检测，确认目标状态，再决定下一步。更多平台限制见[工作流](../guide/workflows.md)。

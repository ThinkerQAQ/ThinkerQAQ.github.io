## Deployment

The site is rebuilt by [GitHub Actions](https://github.com/ThinkerQAQ/ThinkerQAQ.github.io/actions/workflows/deploy.yml) when the private content watcher detects a content update. To redeploy the latest private content without changing site code, use **Run workflow** for the deployment workflow on `main`. The same build is published to GitHub Pages and EdgeOne.

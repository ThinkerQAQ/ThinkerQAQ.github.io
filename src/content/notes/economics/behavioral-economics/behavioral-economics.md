## 1. 行为经济学是什么
- 把心理学和经济学相结合，研究人们的行为如何系统性的偏离经济学传统的**理性人**假设

## 2. 行为经济学假说

### 2.1. 非理性
| 新古典经济学理性人假设（狭义） |                 行为经济学假设（行为偏误）                  |
| ---------------------------- | ---------------------------------------------------------- |
| 只在乎自己绝对的收益          | 参照点比较与损失厌恶、社会比较                               |
| 计划和执行一致                | 执行偏离计划(自我控制问题、过度消费、拖沓)                   |
| 只在乎自己的利益              | 复杂的社会性偏好（利他、公平、信任、互惠、报复、愧疚、诚实等） |
| 对概率事件准确判断            | 概率判断偏误（赌徒谬误、热手谬误、过度自信等）                |

## 3. 参照点和损失厌恶

### 3.1. 前景理论
#### 3.1.1. 前景理论是什么
人在面临获利时，不愿冒风险；而在面临损失时，人人都成了冒险家。
损失的痛苦比获得所带来的喜悦更敏感，而损失和获利是相对于参照点而言的，改变评价事物时的参照点，就会改变对风险的态度。 

##### 3.1.1.1. 确定效应
在确定的收益和“赌一把”之间，多数人会选择确定的好处

##### 3.1.1.2. 反射效应
确定的损失和“赌一把”之间，做一个抉择，多数人会选择“赌一把”。称之为“反射效应”。

##### 3.1.1.3. 损失厌恶
白捡的100元所带来的快乐，难以抵消丢失100元所带来的痛苦。称之为“损失厌恶”。
很多人都买过彩票，虽然赢钱可能微乎其微，你的钱99.99%的可能支持福利事业和体育事业了，可还是有人心存侥幸搏小概率事件。称之为“迷恋小概率事件”。

##### 3.1.1.4. 参照依赖
多数人对得失的判断往往根据参照点决定
举例来说，在“其他人一年挣6万元你年收入7万元”和“其他人年收入为9万元你一年收入8万”的选择题中，大部分人会选择前者。称之为“参照依赖”。
#### 3.1.2. 前景理论的缺陷
只是说明了人们会怎样做，而没有告诉人们应该怎样做

## 4. 执行偏离计划
### 4.1. 当下享乐偏误
#### 4.1.1. 时间偏好
- 涉及到今天和未来的决策叫做跨期选择，人们对跨期选择有一个偏好：未来的消费给自己带来的效用水平要低于现在的消费。这叫时间偏好
- 比如同一个苹果，今天吃比明天吃好
#### 4.1.2. 是什么
- 如果今天可以拿到1000元，半年后可以收益2%，那么人们倾向于今天拿到
- 如果半年后可以拿到1000元，一年后可以收益2%，那么人们倾向于一年后拿到
- 以上就是当下享乐偏误：人在进行跨期决策时候会过度夸大当下的享乐，因此凡是涉及当下的跨期选择会变得更加不耐心
    - ![](https://raw.githubusercontent.com/TDoct/images/master/1607770157_20201212165910658_21343.png)
#### 4.1.3. 当下享乐偏误的影响

|             | 新古典经济学（指数折现模型） | 行为经济学假设（当下享乐偏好） |
| ----------- | -------------------------- | ---------------------------- |
| 储蓄消费决策 | 适当消费、适当储蓄          | 过度消费、储蓄不足            |
| 计划与执行   | 计划与执行一致              | 执行偏离计划（拖沓、后悔）     |
| 自我限制     | 无自我限制需求              | 有自我限制需求（能意识到当下享乐偏误的人）             |

#### 4.1.4. 如何解决当下享乐偏误
- 意识到自己的当下享乐偏误是最重要的一步
- 给自己设置内在的或者外在的自我限制机制
- 自我限制机制产品不但有一定的市场需求而且可以提升福利

## 5. 社会性偏好
### 5.1. 是什么
- 主流经济学假设人是自私的，只在乎自己的利益
- 很多时候人不是只在乎自己的利益会呈现出复杂的社会性偏好
### 5.2. 有哪些
#### 5.2.1. 利他、公平偏好
- 独裁者游戏
    - ![](https://raw.githubusercontent.com/TDoct/images/master/1607831869_20201213114146456_24813.png)
- 最后通牒游戏
    - ![](https://raw.githubusercontent.com/TDoct/images/master/1607831871_20201213114157564_26077.png)
- 两者对比
    - 共同：分配者的利他倾向，或者不公平的厌恶倾向在两个游戏中应该是一样的
    - 差别：分配者认为的接受者的不公平厌恶程度导致了他们分配的增加
##### 5.2.1.1. 影响
- 利他主义
    - 公共政策
    - 与慈善捐款行业有关
- 不公平厌恶
    - 会影响企业的定价策略（价格粘性）
    - 工资长期增长
#### 5.2.2. 信任、互惠
- 信任游戏
    - ![](https://raw.githubusercontent.com/TDoct/images/master/1607831873_20201213115135135_9344.png)
    - 信任更多来自于追求汇报的预期，而被信任程度则是对这种预期的回报
- 信任与被信任程度可以得到量化衡量
    - ![](https://raw.githubusercontent.com/TDoct/images/master/1607831877_20201213115342939_9836.png)
- 互惠机制广泛影响人们生活决策。但互惠机制的效果长期可能减弱
    - ![](https://raw.githubusercontent.com/TDoct/images/master/1607831881_20201213115721063_13466.png)
    - ![](https://raw.githubusercontent.com/TDoct/images/master/1607831885_20201213115738466_9706.png)

#### 5.2.3. 社会形象
- 就是希望在其他人心里留下好的印象
- 人们很多社会行为受到社会形象和社会压力的影响
- 社会形象的考虑在捐款中占据了主要地位

## 6. 概率判断偏误
### 6.1. 是什么
- 人的概率判断会系统性偏离贝叶斯法则。
    - 人们往往会忽略先验概率，而在很小样本里面就期望样本均值打到期望值，导致产生了赌徒谬
### 6.2. 有哪些
#### 6.2.1. 忽略先验概率
- ![](https://raw.githubusercontent.com/TDoct/images/master/1607837340_20201213132030648_14174.png)
- ![](https://raw.githubusercontent.com/TDoct/images/master/1607837342_20201213132055734_26633.png)
#### 6.2.2. 小数定理
- ![](https://raw.githubusercontent.com/TDoct/images/master/1607837344_20201213132301663_10087.png)
##### 6.2.2.1. 赌徒谬误
- 赌局：扔硬币，正面赢，反面输了
- 赌徒谬误：一个赌徒在**连续输了三把**之后，坚信**下一把一定会赢**，因此继续赌博
    - 因为他相应平均来说输赢应该是一半一半
##### 6.2.2.2. 热手谬误
> 小修说明：现代研究对“热手效应”在不同场景中是否存在、强度多大有更细致的讨论。这里保留原笔记记录的经典“热手谬误”框架，不把它理解成所有连续成功都只是错觉。

- 热手谬误：一个赌徒在**连续赢了五把**以后，相信今天有幸运之神的眷顾，他有一双热手，**下一把一定会赢**，因此继续赌博
    - 因为他觉得正常情况下（大数定理）不可能连续出现五把赢面。所以反推今天自己运气特别好。即出现赢面的先验概率大于50%

#### 6.2.3. 过度自信
- 人们往往对自己产生过度自信
- 过度自信会导致人们过度参与竞争、过度交易或者CEO过度从事兼并收购行为

#### 6.2.4. 投射偏误
- 人们过度使用当下的感知去为未来做决策
- 影响了人们各式各样的购物决策，增加了反悔的概率

### 6.3. 概率判断偏误的应用
- 短期：赌徒谬误。相信回报会回归到平均值
    - 卖回报好的股票，买回报差的股票 -> 回报好的股票价格变低，回报率上升 -> 回报率呈现正相关
- 长期：热手谬误。相信连续产生高回报的股票确实与众不同
    - 买回收好的股票，卖回报差的股票 -> 回报好的股票价格变高，回报率下降 -> 回报率呈现负相关

## 7. 基于行为经济学的政策设计
### 7.1. 商业政策
- 传统的经济学认为，即使个体有决策偏误，市场会纠正这种偏误
    - 经验会降低偏误，因而市场竞争会逐步使人变得更加理性
    - 非理性的人无法在市场中存活下去
- 实际市场如何应对消费者的决策偏误
    - 人能够通过学习降低自己的行为偏误变得更加的理性
    - 每个人每次的损失可能是有限的，这不会使我们达到倾家荡产
    - 用来偏离或纠正这个非理性投资者行为的工具是有限的的
### 7.2. 公共政策
- 传统的政策基于理性人假设
    - 一般认为没有政策干预的必要
    - 即时干预，也需要支付很大的成本才能改变人们的行为
- 行为经济学的政策认为人可能有非理性行为
    - 某些情况下有干预的必要
    - 不需要支付很大成本就能通过机制设计改变人们的行为

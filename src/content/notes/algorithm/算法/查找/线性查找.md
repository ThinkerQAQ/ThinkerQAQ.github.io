## 1. 线性查找
## 2. 实现

```go
//O(N)
func LinearSearch(data []model.Comparable, target model.Comparable) int {
	for i := 0; i < len(data); i++ {
		if data[i].CompareTo(target) == 0 {
			return i
		}
	}

	return -1
}
```

func TestLinearSearch(t *testing.T) {

## 1. 线程状态枚举类

```java
public enum State {
    //new后的Thread，没有start
    NEW,

    //start后的Thread，可能没有得到CPU
    RUNNABLE,

    //等待monitor的Thread
    BLOCKED,

     //调用了Object.wait(),Thread.join,LockSupport.park()的线程处理等待状态
    WAITING,

     //调用了Thread.sleep,Object.wait(long),Thread.join(long) ,LockSupport.parkNanos,LockSupport.parkUntil的线程
    TIMED_WAITING,

    //完成运行的线程
    TERMINATED;
}
```

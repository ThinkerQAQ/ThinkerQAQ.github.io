## 1.6. 像素和文件大小


总大小 = 像素数 × 每像素字节数


6016*4016=24160256=2400W像素=24MP

每个像素使用RGB三个通道,每个通道使用8bit,那么3*8=24bit=3B
那么理论上JPEG=2400W*3B=7200W,压缩比为3的话那么最终大小2700WB=27M


而RAW的话


| 格式         | 位深     | 每像素         |
| ---------- | ------ | ----------- |
| RAW（12bit） | 12 bit | ≈ 1.5 Byte  |
| RAW（14bit） | 14 bit | ≈ 1.75 Byte |

24MP*1.75=42M



没理解,为什么RAW是用位深,JPEG是使用通道RGB?

RAW 是“测量数据”，JPEG 是“渲染结果”

RAW：还没变成图片 → 所以用“位深”描述精度
JPEG：已经是图片 → 所以用“RGB通道”描述颜色

| 维度      | RAW           | JPEG       |
| ------- | ------------- | ---------- |
| 数据阶段    | 传感器原始数据       | 已处理图像      |
| 每像素信息   | 单通道（R/G/B之一）  | 三通道（RGB全有） |
| 精度      | 12bit / 14bit | 8bit       |
| 是否压缩    | 无损或轻压缩        | 有损压缩       |
| 是否可直接显示 | ❌ 不行          | ✅ 可以       |

## 2.2. 选择影响区域

FX：2400W像素
DX：1000W像素

一直用FX即可，DX相当于FX在相机内裁切

| 项目    | FX | DX      |
| ----- | -- | ------- |
| 传感器使用 | 全部 | 中间裁切    |
| 视角    | 广  | 窄（1.5x） |
| 分辨率   | 高  | 低       |
| 画质    | 最优 | 略降      |


如果长焦可以通过广角裁切得到,那么是不是只要广角就行了

结论先给：不成立。广角裁切 ≠ 真正的长焦。裁切只是“数字放大”，无法替代长焦在成像质量和空间表现上的差异。


裁切的本质：丢像素换视角

假设你用 24mm 拍一张 2400 万像素的照片，然后裁成等效 120mm 的视角：

120 / 24 = 5 倍焦距
面积缩小 = 1 / 5² = 1/25
实际剩余像素 ≈ 2400万 / 25 ≈ 96万像素

→ 结果：画面确实“变近了”，但分辨率严重下降。

核心结论：

裁切只能改变“取景范围”
无法增加“细节信息”


| 维度    | 广角裁切  | 真长焦 |
| ----- | ----- | --- |
| 视角    | ✅可以模拟 | ✅   |
| 分辨率   | ❌下降   | ✅高  |
| 细节    | ❌损失   | ✅保留 |
| 景深/虚化 | 可能不同，取决于最终构图、光圈和观看尺寸 | 取决于镜头与拍摄参数 |
| 透视/空间压缩 | **同一机位裁切后可保持相同透视** | 透视仍由机位决定 |
| 噪点    | ❌更差   | ✅更好 |

## 2.8. 动态D-Lighting
在高反差场景里，尽量“压高光 + 提阴影”，让亮部不过曝、暗部不死黑（主要针对 JPG 直出）

即
主要在机内处理阶段压缩场景反差、保护高光并提亮暗部，具体曝光和曲线策略由相机决定。

👉 可以把它理解为面向 JPEG/机内渲染的自动动态范围优化，而不是固定的“先减曝光再提阴影”公式。

## 2.9. 长时间曝光降噪
针对慢门拍摄（通常 ≥1 秒）**的一项降噪机制


流程是两步：

正常拍一张（曝光 N 秒）
再拍一张同样时长的“黑帧”（Dark Frame）
用黑帧去减掉：
热噪点（hot pixels）
长曝光产生的固定噪声

👉 本质：暗帧减法（Dark Frame Subtraction）

二、最直观的影响
项目	开启	关闭
噪点（尤其彩色点）	更少	更明显
拍摄时间	×2（很关键）	正常
连续拍摄能力	很差	正常

👉 重点：

曝光 10 秒 → 实际要等 20 秒

## 2.20. 多重曝光

在 尼康 Z5 里，多重曝光（Multiple Exposure）是一个创作类功能，核心是：

把多张照片“叠加”在一起，生成一张合成图

## 2.21. HDR
在 尼康 Z5 里，HDR（高动态范围）是一个机内合成功能，核心是：

Z5 会拍摄 **两张不同曝光** 并在机内合成为 HDR JPEG；还可以选择保存用于合成的单张 NEF（RAW）原片。


| 功能         | 本质         |
| ---------- | ---------- |
| 自动包围       | 拍多张        |
| HDR        | **自动合成一张** |
| D-Lighting | 单张优化       |
HDR 和自动包围都涉及多曝光，但 Z5 的 HDR 是独立的两张曝光 + 机内合成功能；自动包围则只是按设定拍摄多张，不会自动合成。



### 2.21.1. 尼康Z5自带的HDR比起lightroom中合成HDR区别是什么

| 动态范围 | 一般      | 更高            |

## 2.22. 焦距变化拍摄

### 2.22.1. 为什么尼康Z5焦距变化拍摄，我设置了100张，步长为1，光圈为F4，但是实际只拍摄了22张


焦距变化拍摄的逻辑不是“强制拍满张数”，而是：

从近到远逐步移动对焦 → 当达到“无限远”或已无可用对焦位置时停止

因此：

你设置的 100张 = 最大上限
实际拍摄张数 = 覆盖完整景深所需的最小张数

👉 所以只拍了 22 张，说明：

在第 22 张时，对焦很可能已经推进到无限远附近，因此相机提前结束。Z5 官方说明也明确：达到无限远时，可能在设定张数拍完之前结束。

### 2.22.2. 焦点堆栈，曝光堆栈是什么意思。LightRoom中如何处理
1️⃣ 焦点堆栈（Focus Stacking）

目的：解决景深不够的问题

多张照片，每张对焦在不同距离
每张只清晰一部分（前景 / 中景 / 远景）
合成后 → 整张从近到远都清晰

典型场景：

微距（昆虫、花）
风光（前景石头 + 远山）
2️⃣ 曝光堆栈（Exposure Stacking / HDR）

目的：解决动态范围不够的问题

多张照片，不同曝光（欠曝 / 正常 / 过曝）
每张保留不同亮度信息：
欠曝 → 保住高光（天空）
过曝 → 保住暗部（地面）

合成后 → 高光不过曝 + 阴影有细节

典型场景：

逆光（室内 + 窗外）
日落 / 夜景

| 类型        | 解决问题  | 变化维度 | 最终效果 |
| --------- | ----- | ---- | ---- |
| 焦点堆栈      | 景深不足  | 对焦距离 | 合成后扩大景深 |
| 曝光包围/HDR 合并 | 动态范围不足 | 曝光   | 保留更多高光和阴影细节 |

Lightroom Classic 可以直接做 HDR 合并；普通的“堆叠（Stack）”只是目录组织，不会自动做焦点合成。焦点堆栈通常需要 Photoshop 的 Auto-Align/Auto-Blend 或其他专门堆栈工具。
### 2.22.3. 动态范围是什么意思？HDR就是曝光堆栈么
一、动态范围（Dynamic Range）是什么

定义：
相机能同时记录的 最亮细节 和 最暗细节 之间的范围。

可以理解为：

一张照片里，既能看到太阳附近的云层细节，又能看到阴影里的纹理，这个能力就是动态范围。


| 概念       | 含义           |
| -------- | ------------ |
| HDR（结果/工作流）  | 用更大动态范围表示或合并场景亮度信息 |
| 曝光包围 + 合并（方法） | 生成 HDR 图像的一种常见方式 |

## 3.2. 对焦模式

一、对焦模式（AF Mode）

决定的是：对焦如何“工作”

1）AF-S（单次自动对焦）
半按对焦 → 锁定
不会持续追焦

👉 视频结论：
基本不适合视频（除非完全静态）

2）AF-C（连续自动对焦）
持续跟踪对焦
适合运动目标

👉 视频结论：
可用，但不是视频默认最优

3）AF-F（全时自动对焦 / 视频专用）
相机自动持续调整对焦
无需半按
对焦变化更平滑

👉 视频结论（关键）：
视频优先使用 AF-F

二、AF 区域模式（AF Area Mode）

决定的是：对焦“看哪里”

1）自动区域 AF（人脸/眼睛检测）

## 3.3. 减震 电子减震
一、先给结论（避免你走弯路）
机身/镜头 VR 与电子减震解决问题的方式不同。通常先依靠光学/机身防抖保持画质和视角，电子减震在视频中可作为额外稳定手段，但会带来裁切等代价。
二、减震（VR）——物理防抖
原理
机身 5 轴防抖（IBIS）
通过传感器位移抵消抖动
特点
不裁切画面
画质无损
稳定性自然（不会“果冻感”）
在 Z5 上表现
静态手持：效果很好
轻微移动：可用
走路：不够（会抖）

👉 结论：
手持时通常可以开启 VR；使用稳定三脚架、特定镜头或特殊拍摄方式时是否关闭，应参考镜头/机身说明和实际测试。

三、电子减震（Electronic VR）——算法防抖
原理
裁切画面 + 软件算法稳定
特点
会裁切画面（视角变窄）
有可能产生“果冻感 / 扭曲”
对走路视频有一定改善
实际效果（Z5）
优点
手持走路稍微稳一点
比纯 VR 更“抗晃”
缺点（重点）
广角变不够广（很明显）
画面边缘可能变形
夜景更容易糊（裁切后等效更长焦）


六、组合使用建议（结合你）

你常拍：风景 + 城市 + 徒步

场景 1：风景静态（你最常见）
VR：开
电子减震：关

👉 最干净画质

场景 2：手持慢移动（轻微扫）
VR：开
电子减震：可选（一般关）
场景 3：走路拍（扫街）
VR：开
电子减震：开

👉 但要接受：

画面裁切
轻微变形
七、一个更本质的认知（很关键）

稳定画面的优先级是：

稳定器（云台）
 > 机身减震（VR）
 > 电子减震

👉 电子减震本质是“补救手段”，不是主力方案


## 3.4. 衰减器

一、音频衰减器是什么

本质是降低音频输入灵敏度/增益余量，以减少高声压环境中的削顶失真；具体衰减量以 Z5 的实现为准，不需要把它理解成固定的 -20 dB 公式。

作用只有一个：
👉 防止声音“爆音 / 削顶（clipping）”

二、什么时候需要开
1）高声压环境（必须开）
演唱会
酒吧
地铁 / 车流密集街道
高声压环境（是否与风噪有关要区分；风噪主要应使用物理防风和风噪降低功能）

👉 不开会发生：

波形顶死（削顶）
声音刺耳、失真（不可恢复）
2）你靠得很近录音
对着人说话很近
收音设备离声源 < 30cm

👉 防止瞬间爆音

三、什么时候不要开
1）正常环境（你最常见）
日常 vlog
风景环境声
安静街道

👉 开了会导致：

声音过小
底噪被放大（后期拉音量）

## 3.5. 频响

你看到的“频响”，在尼康 Z5 视频菜单里指的是麦克风频率响应设置：

麦克风频率响应（Frequency Response）

它控制的是：
👉 相机更偏向录制哪一段频率的声音（低频 / 中频 / 高频）

一、Z5 的频响选项
通常有两个：
1）宽频（Wide Range）


记录完整频段（低频 + 中频 + 高频）


更接近真实环境声音


👉 特点：


声音自然、通透


但容易收进风声、环境噪音



2）语音（Voice Range）


重点保留更适合人声清晰度的频段


抑制低频和部分高频


👉 特点：


人声更清晰


环境音被削弱



二、本质区别（技术层面）
模式处理方式宽频接近“平直频响”语音可以理解为相机对录音频率范围进行取舍，以突出人声可懂度
👉 可以理解为：


宽频 = 原始输入


语音 = 已做简单 EQ 处理



三、怎么选（结合你使用场景）
你主要是：风景 + 偶尔视频

场景 1：风景 / 环境氛围（推荐）
频响：宽频
👉 原因：


保留风声、水声、环境层次


更有“现场感”



场景 2：Vlog / 说话
频响：语音
👉 原因：


人声更突出


背景噪音被压制



场景 3：嘈杂环境（地铁/街道）
频响：语音
👉 否则人声会被淹没


## 3.6. 降低风噪
你问的是 Z5 视频菜单里的**“降低风噪（Wind Noise Reduction）”。这是一个针对风噪的机内音频处理功能，核心作用是减轻风吹麦克风产生的低频“呼呼声”。

一、它到底在做什么
风噪通常包含很强的低频能量，相机会削弱这类成分；具体滤波实现并未作为用户可调参数公开，不需要把它固定理解成某个截止频率。

👉 结果：

风声减弱
同时低频环境音也会被一起削掉
二、什么时候应该开
1）户外有风（推荐开启）
湖边、海边（你拍西湖这类场景）
山上、桥上
风明显吹到麦克风

👉 否则录出来是：

“呼——呼——”的低频噪声，基本不可用

2）走路拍视频
风会叠加运动气流
👉 开启有收益
三、什么时候不要开
1）无风 / 室内

👉 开了只会：

声音变薄
环境氛围变差
2）你需要保留环境低频

比如：

水流声（溪流、海浪）
城市低频氛围

👉 风噪过滤会把这些一起削掉

四、效果边界（重要）

这个功能不是万能的：

能解决：
轻度风噪 ✅
解决不了：
大风直吹麦克风 ❌
强气流冲击 ❌

👉 一旦“爆风”，音频基本不可救

五、正确的优先级（工程思维）

降低风噪的有效顺序是：

物理防风（最重要）
 > 拍摄环境选择
 > 麦克风方向
 > 降低风噪（菜单）
六、实际可执行方案
1）最有效：物理防风
海绵套（基础）
毛套（deadcat，强烈推荐）

👉 这个比菜单有用一个量级

2）机位控制
背对风拍
利用建筑 / 树挡风
3）菜单组合（Z5）
有风场景
降低风噪：开启
频响：宽频 或 语音（看是否要人声）
衰减器：关闭（除非声音很大）
无风场景
降低风噪：关闭
频响：宽频

DSC_0002.JPG
...

这个设置决定：

编号是一直累计，还是会重置

## 4.23. 将设置应用于即使取景
一、它在控制什么？

屏幕/取景器里看到的画面，是否实时反映当前曝光设置

二、两种模式
1️⃣ 开启（ON）✅推荐

👉 所见即所得（WYSIWYG）

效果：

你调暗 → 画面立刻变暗
你调亮 → 画面立刻变亮

👉 看到的 ≈ 拍出来的

2️⃣ 关闭（OFF）

👉 显示被“标准化”

效果：

不管你怎么调曝光
画面看起来都差不多亮

👉 实际拍出来可能完全不同

## 4.24. 取景网格显示

一、它在做什么？

在取景画面上显示网格线（通常是 3×3 九宫格）

👉 不会出现在最终照片中，只是辅助你构图

二、结论（直接给）

👉 建议：开启（ON）


## 4.25. 峰值对焦辅助加亮显示
一、它在做什么？

把“已经对焦清晰的区域”用颜色高亮出来

表现为：

画面中清晰边缘会出现彩色轮廓（红/黄/白等）
二、结论（直接给）

👉 建议：开启（ON）

## 4.26. 连拍模式下查看全部

当你使用连拍（Burst/Continuous）拍了一组照片后，回放时是否逐张显示全部照片

二、两种模式
1️⃣ 开启（ON）

👉 回放时：

连拍的每一张都会显示
一张一张翻

效果：

拍了10张 → 回放看到10张
2️⃣ 关闭（OFF）✅常用

👉 回放时：

只显示连拍中的“关键帧”（通常是第一张或一组代表）
回放界面会以组的方式组织连续拍摄照片，而不是把这个选项理解成“其他照片不存在”；具体展开方式以当前固件回放界面为准。

## 字节


### InputStream
- read
返回从InputStream流内读取到的一个字节内容。
当读完所有数据后返回-1.-1是一个int类型，不是byte或者char类型，这是不一样的。
- read(byte[])
尝试读取与给定字节数组容量一样大的字节数，返回值说明了已经读取过的字节数

### OutputStream
- Write(byte)
只有int类型的第一个字节会被写入，其余位会被忽略。
- write(byte[])
字节数组中所有数据写入到输出流中。
- flush()
把数据从缓冲区刷入磁盘

## 字符


### Reader
- read
返回读取的字符，int类型（0-65535）之间。到达末尾返回-1
他会根据文件的编码读取一个或多个字节

### Writer
- write
将低16位写入Writer

The producer–consumer pattern separates work creation from work processing through a shared queue or channel. Producers enqueue units of work; one or more consumers process them independently.

A production design needs **bounded capacity** and backpressure. An unbounded queue can convert overload into memory exhaustion and extreme latency. Also define concurrency, ordering, retry, shutdown/drain behavior, and duplicate-processing semantics.

Design patterns give names to recurring collaboration structures. Creational patterns manage construction, structural patterns compose objects/types, and behavioral patterns organize interaction and varying policy.

A pattern is useful when it clarifies a real design force. Do not force a pattern because a codebase “should use patterns”; many patterns collapse into simpler language features in modern languages.

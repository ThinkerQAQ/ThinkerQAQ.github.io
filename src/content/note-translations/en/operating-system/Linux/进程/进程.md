A Linux process is a resource and protection context containing an address space, credentials, file descriptors, signal state, namespaces/cgroups, and one or more schedulable threads/tasks.

Processes are created through kernel primitives exposed by higher-level APIs such as `fork`/`exec` or runtime process-launch functions. Parent/child relationships matter for exit status and zombie reaping.

Signals provide asynchronous notifications/control, but robust service lifecycle also requires explicit shutdown, child management, resource limits, and supervision.

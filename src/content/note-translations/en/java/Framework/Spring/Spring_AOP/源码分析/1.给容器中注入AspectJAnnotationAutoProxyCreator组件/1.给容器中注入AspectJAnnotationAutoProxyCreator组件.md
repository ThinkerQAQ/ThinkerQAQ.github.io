Annotation-driven Spring AOP registers infrastructure that participates in bean creation and decides which beans should be proxied.

Historically this includes `AnnotationAwareAspectJAutoProxyCreator`-family infrastructure registered by AOP configuration/import machinery. The component is a `BeanPostProcessor`-style auto-proxy creator, so it can inspect beans and return proxies around matching targets.

Exact registrar/configuration classes change across Spring releases; the durable idea is **enable AOP → register auto-proxy infrastructure → post-process eligible beans**.

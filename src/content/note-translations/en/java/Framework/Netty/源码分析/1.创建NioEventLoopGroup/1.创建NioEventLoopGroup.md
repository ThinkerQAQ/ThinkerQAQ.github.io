`NioEventLoopGroup` represents a group of selector-backed event loops. During construction, Netty creates child event loops, associates executors/thread factories, and installs a chooser that assigns channels/tasks to those children.

The durable model is **one group → multiple event loops → each registered channel is normally handled by one event loop for its lifecycle**. This thread confinement greatly reduces synchronization needed in channel handlers.

Constructor parameters, chooser implementation, and defaults are version-specific; inspect the exact Netty tag for source-level details.

## 1. Purpose

`CountDownLatch` starts with a count N.

- `await()` waits while the count is greater than zero;
- `countDown()` decrements it;
- when the count reaches zero, current/future awaiters can proceed.

## 2. One-Shot

A latch cannot be reset to a new count. Use `CyclicBarrier`, `Phaser`, or another mechanism for reusable phases.

## 3. Example

```java
CountDownLatch done = new CountDownLatch(workers);
for (...) {
    executor.execute(() -> {
        try {
            doWork();
        } finally {
            done.countDown();
        }
    });
}
done.await();
```

Use `finally` so failures do not accidentally leave the latch permanently nonzero.

## 4. Memory Semantics

Actions before a thread calls `countDown()` happen-before actions following a successful return from another thread's corresponding `await()` once the count reaches zero.

## 5. AQS

The count is naturally represented by AQS shared state: awaiters acquire in shared mode when state reaches zero; countdown releases shared waiters.

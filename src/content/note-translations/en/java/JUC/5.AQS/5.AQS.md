## 1. What AQS Is

`AbstractQueuedSynchronizer` is a framework for building blocking synchronizers around:

- an integer synchronization `state`;
- atomic state transitions;
- a queue of waiting threads;
- park/unpark mechanics;
- exclusive or shared acquisition modes.

`ReentrantLock`, `Semaphore`, `CountDownLatch`, and related JUC classes are built around AQS-style synchronization mechanisms.

## 2. Template Method Design

Subclasses define policy by implementing methods such as:

- `tryAcquire` / `tryRelease`;
- `tryAcquireShared` / `tryReleaseShared`;
- ownership checks where applicable.

AQS provides queueing, cancellation, interruptible/timed acquisition, and wake-up machinery.

## 3. Acquisition Model

Simplified exclusive flow:

1. try fast-path state acquisition;
2. if it fails, enqueue the thread/node;
3. wait until predecessor position permits a new attempt;
4. park when useful rather than busy-spin indefinitely;
5. on release, wake an eligible successor.

## 4. Shared Mode

Shared synchronizers allow multiple successful holders according to state policy—for example permits in a semaphore or release propagation in a latch.

## 5. Source Version Caveat

AQS internal node fields, status constants, VarHandle/Unsafe usage, and queue algorithms have changed across JDK releases.

Learn the state + queue + park/unpark abstraction first; read source from the exact JDK version when investigating implementation details.

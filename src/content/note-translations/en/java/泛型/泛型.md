Java generics provide compile-time type safety and reusable parameterized APIs such as `List<String>`.

Most generic type information is implemented through **type erasure**, so runtime representation does not preserve every source-level type argument. This explains restrictions such as `new T()` and generic array creation.

Bounds (`T extends X`) constrain type parameters. Wildcards express variance at use sites. A useful mnemonic is **PECS**: producer `extends`, consumer `super`.

Do not use raw types unless compatibility forces it; they bypass generic checking and move errors toward runtime.

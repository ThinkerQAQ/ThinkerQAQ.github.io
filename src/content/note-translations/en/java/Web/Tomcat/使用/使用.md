Tomcat is a Servlet/Jakarta web container and HTTP server implementation. Applications can be deployed as web applications or embedded through frameworks depending on architecture.

Important operational areas are connector ports/TLS/proxy settings, application context configuration, logging, thread/connection limits, graceful shutdown, and JVM/container resource limits.

Configuration names and Servlet namespace compatibility depend on Tomcat major version. Verify deployed-version documentation instead of copying an old `server.xml` recipe unchanged.

For source analysis, check out an exact Tomcat release/tag and use that version's documented build prerequisites rather than an old IDE-specific recipe.

A useful workflow is: build/test from the project's supported build system, import the project into the IDE, run the normal bootstrap/test entry point, then attach breakpoints to one request path.

Record the exact Git tag/JDK because source layout, Servlet/Jakarta dependencies, generated files, and build requirements vary significantly across versions.

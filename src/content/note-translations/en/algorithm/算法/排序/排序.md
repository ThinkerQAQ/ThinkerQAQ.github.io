Sorting choices depend on more than big-O: stability, extra memory, worst-case guarantees, input size/distribution, locality, and whether data fits memory all matter.

Elementary insertion sort is excellent for tiny/nearly sorted ranges; merge sort offers stable predictable `O(n log n)`; quicksort-style algorithms have strong practical locality/average performance; heap sort offers in-place worst-case `O(n log n)`.

Production libraries usually combine algorithms rather than using one textbook implementation unchanged.

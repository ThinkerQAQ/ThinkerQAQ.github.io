Testing validates behavior under defined assumptions; performance testing measures how a system behaves as workload and resource pressure change. Distinguish functional correctness from latency, throughput, capacity, saturation, and failure behavior.

A useful performance result records workload shape, dataset, environment, version, concurrency, request mix, latency percentiles, errors, and resource utilization. A single QPS number without those conditions is not portable evidence.

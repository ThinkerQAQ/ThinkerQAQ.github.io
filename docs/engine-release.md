# Inkerio source releases / 引擎源码发布

Inkerio engine tags use `inkerio-v*`; the companion application keeps `blogctl-v*`. Engine archives contain versioned source, the MIT license and third-party notices, not a compiled personal website, node_modules or BlogCTL executables. Install Node.js/npm and Go, then follow the [Quick Start](quick-start.md) with the public content template.

BlogCTL release links and the repository latest-release pointer remain reserved for the companion app. Source snapshots do not certify the separate binary distribution: consult [third-party notices](../THIRD_PARTY_NOTICES.md) for the current fhttp license blocker before redistributing a BlogCTL executable. Article, photography and private content licensing remain separate.

# ThinkerQAQ

[English](README.md)

个人网站：[thinkerqaq.com](https://thinkerqaq.com/)

使用 [Inkerio](https://github.com/ThinkerQAQ/inkerio) 构建。

## 部署

私有内容仓库更新后，内容监控工作流会触发 [GitHub Actions 部署](https://github.com/ThinkerQAQ/ThinkerQAQ.github.io/actions/workflows/deploy.yml)。如需在不修改网站代码的情况下重新发布最新内容，可在 `main` 分支上通过 **Run workflow** 手动触发。一次构建同时发布到 GitHub Pages 和 EdgeOne。
